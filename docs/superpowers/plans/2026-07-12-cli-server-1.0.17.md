# CLI Server 1.0.17 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 使 CLI v3、Runtime Host 和 Windows Service 模板达到 1.0.17 审计基线，并以可重复测试证明模板、生命周期、帮助、兼容性和安装引用正确。

**Architecture:** 保持单进程单 Runtime Host、Frame 为唯一 JSON 输出、catalog v3 可选元数据向后兼容。最小模板与业务示例分离；描述性登记、Runtime 托管执行和 HostedService 使用明确来源字段区分。

**Tech Stack:** C#/.NET 10、Microsoft.Extensions.Hosting、System.Text.Json、RuntimeDiagnosticFrame、PowerShell 发布验证。

# iwesun Runtime promotion plan and launch copy

[中文](../PROMOTION_PLAN.md) · [Overview](../../README.en.md) · [User guide](USER_GUIDE.md)

Updated: 2026-10-09. These are recommendations and prepared copy, not a claim that external posts, listings or partnerships already exist.

## Lead with one reproducible workflow

**An authorized AI assistant uses a structured CLI to inspect and debug a .NET service, with coordinated lifecycle management.**
Introduce Data, WebView2 and networking as related reusable components rather than leading with a long feature inventory.
Initial readers: .NET/Windows Service developers, AI coding-tool users and WebView2 application authors.

## Suggested sequence

1. Ship bilingual onboarding, clickable keywords, Topics, release assets, accurate license wording and issue templates. GitHub Topics associate repositories with relevant subjects; they do not guarantee ranking. [Official documentation](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/classifying-your-repository-with-topics)
2. Prepare a reproducible SampleHost walkthrough: startup, managed-task inspection, allowlisted state access, a specific diagnosis, verification and shutdown. A 60–90 second recording can support it; no such recording has been produced yet.
3. Consider a Chinese launch on [V2EX's creator showcase](https://www.v2ex.com/go/create), with a real development story and runnable example. Check current community/account rules first.
4. Consider [Show HN](https://news.ycombinator.com/showhn.html) after English onboarding works. The author must have personally worked on the project, make it usable and be available to discuss it. Do not submit only a landing page or organize votes.
5. Follow up with focused articles based on actual feedback: service shutdown, RecordStore, changing DOMs and request correlation. Include reproducible examples, versions and limits; share only where self-promotion is allowed.

Do not start with purchased stars, unsolicited bulk messages or paid promotion. Make the first run work for unfamiliar users before expanding reach.
External posting, account representation, paid campaigns and partnership commitments need separate authorization.

## English launch copy

**iwesun Runtime: CLI-driven AI diagnostics and lifecycle management for .NET services**

I have published the first public beta of iwesun Runtime, a reusable foundation for runtime diagnostics and service management.

After integration and authorization, an AI assistant or operator can inspect application state, trace execution, access allowlisted members and check debugging results through a structured CLI. Managed processes, threads, tasks and service shutdown follow a coordinated lifecycle.
Companion components provide small in-memory relational tables through Data/RecordStore, WebView2 control, and parallel network endpoints with asynchronous responses.

The repository includes Chinese and English onboarding, samples, tests, Debug/Release DLLs, MSI/ZIP downloads and an AI integration skill. This is a beta: real-browser, exact-network-access and endurance behavior still need target-environment validation.

The license is noncommercial source-available, not OSI open source. Noncommercial use is free with notices preserved; commercial use needs separate permission, and independent modified distributions require approval.

Try the samples, report a reproducible issue, or apply to join the working group.
